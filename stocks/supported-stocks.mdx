OwnFlow starts with the tokenized stocks that have a Chainlink price feed, so every purchase can be checked against a price that is not the trading pool's own.

| | | |
|---|---|---|
| AAPL | MSFT | NVDA |
| GOOGL | AMZN | META |
| TSLA | MSTR | CRCL |
| INTC | SNDK | SPCX |
| ANT | | |

More stocks are added one by one, once each has a safe price source.

<Warning>
  SPCX and ANT are tokens for private companies. Their price feeds are reference values, not live market prices.
</Warning>
